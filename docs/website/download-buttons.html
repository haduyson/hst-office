Linux

Ubuntu / Debian 64-bit (gói .deb)

Tải cho Linux (.deb, tar.gz) HSTOffice_1.0.0_Linux_x86-64_deb.tar.gz

Kiểm tra tệp tải về (SHA-256)

Mã kiểm tra của mọi tệp nằm trong SHA256SUMS. So sánh với kết quả của lệnh: Windows certutil -hashfile <tệp> SHA256; macOS shasum -a 256 <tệp>; Linux sha256sum -c SHA256SUMS --ignore-missing.

Windows: cảnh báo SmartScreen

Bộ cài chưa được ký số nên Windows có thể hiện “Windows đã bảo vệ PC của bạn”. Chọn Thông tin bổ sung (More info) → Vẫn chạy (Run anyway).

macOS: Gatekeeper

Nếu macOS báo không mở được vì chưa xác minh nhà phát triển: mở tệp .dmg, kéo HST Office vào Applications, rồi nhấp chuột phải (Control-click) vào HST Office → Mở → Mở. Hoặc vào Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở.

Linux

tar -xzf HSTOffice_1.0.0_Linux_x86-64_deb.tar.gz, vào thư mục vừa giải nén, chạy sha256sum -c SHA256SUMS rồi sudo apt install ./*.deb.
