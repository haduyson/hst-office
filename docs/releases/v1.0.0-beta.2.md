## Điểm mới so với beta 1

- **Mở nhiều tài liệu dạng tab** trong một cửa sổ (như trình duyệt); bật sẵn, tắt được trong Tùy chọn.
- **Bộ icon ứng dụng HST mới** cho Windows, macOS, Linux (lối tắt desktop, menu, taskbar, Dock, cửa sổ).
- **Trình cài đặt hoàn toàn tiếng Việt** trên mọi ngôn ngữ Windows, hình ảnh HST mới; mô tả gói Linux tiếng Việt.
- **Sách hướng dẫn tiếng Việt** mở bằng F1 / Trợ giúp, dùng được khi không có mạng.
- **Trình hướng dẫn văn bản hành chính NĐ 30** gọn và rõ hơn, có xem trước.
- Hộp chào mừng mới; thanh kiểu chữ trên giao diện gọn gàng; tiêu đề cửa sổ hiển thị phiên bản HST.
- Bản dịch giao diện được rà soát thêm về thuật ngữ.
- **macOS** (Apple Silicon và Intel) — nếu tệp `.dmg` có trong danh sách tệp bên dưới.

## Tệp tải về

| Tệp | Nền tảng |
|---|---|
| `HSTOffice_1.0.0_Win_x86-64_en-US_vi.msi` | Windows 10/11 64-bit |
| `HSTOffice_1.0.0_Linux_x86-64_deb.tar.gz` | Ubuntu/Debian 64-bit (gói `.deb` + `SHA256SUMS` bên trong) |
| `HSTOffice_1.0.0_macOS_arm64.dmg` | macOS Apple Silicon (M1 trở lên) |
| `HSTOffice_1.0.0_macOS_x86_64.dmg` | macOS Intel |
| `SHA256SUMS` | Mã kiểm tra các tệp trên |

## Cài đặt

**Windows:** chạy tệp `.msi`. Bộ cài **chưa được ký số** nên Windows SmartScreen có thể cảnh báo: chọn *More info* → *Run anyway*.

**macOS:** mở tệp `.dmg`, kéo HST Office vào Applications. Nếu bản chưa ký, macOS sẽ chặn lần mở đầu: nhấn chuột phải vào HST Office → *Open*.

**Linux:**
```bash
tar -xzf HSTOffice_1.0.0_Linux_x86-64_deb.tar.gz
cd HSTOffice_1.0.0_Linux_x86-64_deb && sha256sum -c SHA256SUMS
sudo apt install ./*.deb
hst-office
```

Kiểm tra tệp tải về: Linux/macOS `sha256sum -c SHA256SUMS` (macOS: `shasum -a 256 -c SHA256SUMS`); Windows `certutil -hashfile <tệp> SHA256`.

## Hạn chế đã biết

- Bộ cài Windows chưa ký số; bản macOS có thể chưa ký/notarize.
- Bản dịch tiếng Việt chưa được người bản ngữ rà soát toàn bộ.
- Tiện ích mở rộng chỉ cài từ tệp `.oxt` do người dùng chọn; người dùng tự chịu trách nhiệm với tiện ích bên thứ ba.
