HST Office 1.0.0 beta 1: bộ ứng dụng văn phòng của HASON TECH (Văn bản, Bảng tính, Trình chiếu), giao diện tiếng Việt, giao diện Tabbed (ribbon).

## Tệp tải về

| Tệp | Nền tảng | Ghi chú |
|---|---|---|
| `HSTOffice_1.0.0_Win_x86-64_en-US_vi.msi` | Windows 10/11 64-bit | Tiếng Việt + tiếng Anh |
| `HSTOffice_1.0.0_Linux_x86-64_deb.tar.gz` | Ubuntu/Debian 64-bit | Gói `.deb` + `SHA256SUMS` bên trong |
| `SHA256SUMS` | — | Mã kiểm tra các tệp trên |

## Cài đặt

**Windows:** chạy tệp `.msi`. Bộ cài **chưa được ký số**, Windows SmartScreen sẽ cảnh báo: chọn *More info* → *Run anyway*.

**Linux:**
```bash
tar -xzf HSTOffice_1.0.0_Linux_x86-64_deb.tar.gz
cd HSTOffice_1.0.0_Linux_x86-64_deb && sha256sum -c SHA256SUMS
sudo apt install ./*.deb
hst-office
```

Kiểm tra tệp tải về: Linux `sha256sum -c SHA256SUMS`; Windows `certutil -hashfile <tệp> SHA256`.

## Hạn chế đã biết

- Bộ cài Windows chưa ký số; chưa được kiểm thử cài đặt trên máy Windows thật.
- Bản dịch tiếng Việt chưa được người bản ngữ rà soát toàn bộ.
- Tiêu đề cửa sổ một số nơi còn hiển thị số phiên bản engine (26.8).
- Tiện ích mở rộng chỉ cài từ tệp `.oxt` do người dùng chọn; người dùng tự chịu trách nhiệm với tiện ích bên thứ ba.
